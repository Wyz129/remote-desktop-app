# 虚拟资源管理器

资源管理器在同一行显示后退、前进、目录路径、视图切换、刷新与窗口按钮。路径中的每个目录都可以点击，直接进入相应的上级目录。

路径太长时，优先保留当前目录及附近的上级目录；靠近根目录的部分折叠为省略号。点击路径区域的空白处或省略号，即可编辑完整路径。按 Enter 跳转，Esc 取消输入并保留当前位置；支持绝对路径、相对路径和 `~/`。

键盘操作：

- Ctrl+L 或 F4：选中完整目录路径并开始编辑。
- Alt+↑：上一级目录。
- Alt+← / Alt+→：后退、前进。
- F5：刷新已打开的远程位置。

左侧始终保留 Root、Home、Desktop、Log 和 Trash。Root 指向 `/`，Home 指向 SSH 登录账号的真实用户目录；Desktop 指向当前设置的桌面位置。Log 和 Trash 的默认位置分别为 `~/.rdesktop/log` 与 `~/.rdesktop/trash`。可在设置中调整 Desktop、Log、Trash，添加其它目录快捷方式并改变显示顺序。自定义快捷方式使用文件夹图标。

位置栏、面包屑和手工路径输入遵循同一套服务器访问权限。无法进入目录时保留上一个成功打开的位置，显示“无访问权限”和具体错误；不会因为点击快捷方式绕过权限检查。符号链接打开后显示实际目标路径。

Trash 是目录入口；它不改变原有删除操作的含义。文件右键菜单中的“删除”仍会在确认后永久删除。

传输选择使用同一个资源管理器窗口，左侧位置栏和路径导航同样可用。底部的“选中路径”输入框用于确认上传目标目录或下载项目，顶部路径区域用于浏览目录。
