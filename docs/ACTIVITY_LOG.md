# 本地 CLI 监听与操作日志

适用于 Remote Desktop App 1.1.12。

## 连接通知与实时查看

通过 [CLI](CLI.md) 向指定桌面实例执行 `exec`、`upload`、`download` 或 `cancel` 后，顶栏时间下方显示“检测到本地命令行连接”、IP 来源和连接时间。认证成功的实际请求自动开始记录；无需先点击按钮。`connect` 在连接结果确定后显示通知。`list`、`status`、`focus` 用于发现、检查或唤起实例，不产生操作会话和重复通知。点击顶栏时间可查看本次运行的通知历史，CLI 通知保留打开监听的入口；通知历史上限 200 条，与远程日志独立。

点击通知中的“实时监听”，或顶栏活动图标，可打开监听窗口。窗口分为“系统操作”“第三方访问”“虚拟终端”三个标签，使用类似 Notebook 的 In/Out 块。

- 系统操作显示 `In #访问目录`、`Out #成功`（或 `#失败`）及有界返回值，记录操作时间。应用封装好的文件操作、权限检查、系统信息查询等不再展示内部 SSH 实现源码，相关日志也使用同样的操作摘要。一次高层操作的内部命令不会重复产生记录。
- 第三方访问保留本地 CLI 经实例发送的原始指令、stdout/stderr、结果、错误及取消信息；下拉框可筛选单次连接。点击连接通知会直接定位到该栏和对应会话。
- 虚拟终端按会话聚合原始启动命令、实际输入按键与服务器回复，不将按键解释为推测的 shell 历史。

可关闭自动滚动，拖动、缩放、最小化或关闭窗口。重复打开只恢复同一个窗口；关闭窗口不会停止记录。左侧动态窗口标签可恢复最小化窗口。

命令高亮使用 BSD-3-Clause 的 highlight.js 11.12.0，终端 ANSI 颜色转换使用 MIT 的 ansi_up 6.0.6，依赖及许可证随应用本地打包。显示内容经过 DOMPurify 清理，仅保留颜色用的 span，不执行输出中的 HTML，也不生成可访问网页或文件的输出链接。该视图是有界的活动记录，并非第二个交互式终端；SFTP 操作保留路径与结果摘要，不虚构等价 shell 命令。

每次 CLI 调用使用一次经过实例令牌认证的本地 IPC 连接，对应一个日志会话。Windows 使用命名管道，它没有 TCP 来源 IP；应用不会把客户端自行提交的地址视为来源。若能从已有 SSH 连接取得本机出口地址，会显示为“IP：…（SSH 本机出口地址）”；否则显示“本机命名管道（无网络 IP）”。这不是服务器地址，也不能据此区分同一账号下的本地进程。连接时间使用 ISO 8601 UTC 存储，界面按本机时区显示并标注时区。

## 文件位置与内容

认证后在服务器真实 HOME 下自动初始化 `~/.rdesktop/log`，默认操作日志写入此目录，与桌面位置无关。在“设置 → 目录与侧栏”可修改 Log 路径；它既改变资源管理器 Log 入口，也改变后续操作日志的实际写入位置。路径按主机、端口、账号和已验证指纹分别保存，保存前检查目录访问并尝试创建新日志，失败时报告错误。监听窗口显示具体文件路径；可通过资源管理器 Log 入口或地址栏打开。

| 文件 | 内容 |
| --- | --- |
| `cli-时间-随机标识.log` | 一次本地 CLI 连接的元数据、命令及参数、流式回复、传输进度、退出码或错误 |
| `system-时间-随机标识.log` | GUI 文件导航和操作、权限检查、文档及 Notebook 操作、浏览器导航/下载、内部 SSH 查询的操作名称与结果摘要；`category: terminal` 记录虚拟终端启动命令、原始输入与服务器输出；连接和桌面切换 |

系统日志对 CLI 仅写 `cli-connection`，字段为 `type`、`time`、`ip`、`logPath`，不重复保存 CLI 命令、输出或传输参数。CLI 日志轮换时增加指向新分卷的索引。文件为 UTF-8，每行一个 JSON 对象（NDJSON），可用工作台只读查看或下载后处理。

日志以 8 MiB 为目标，在完整 JSON 记录之间轮换为 `.part002.log` 等分卷，单条超大记录可能让一卷超过该值。旧卷不会自动删除。每条记录带 ISO 时间。未被高层操作包裹的内部 SSH 查询以操作名称表示，其 stdout/stderr 各最多记录 256 KiB，超过上限写入 `output-truncated` 标记；二进制下载不记录文件内容。CLI 仍受其命令输出上限约束。实时窗口仅保留最近 100 个会话、600 条记录和约 2 MiB 内容，单个字段显示最多 32768 字符。应用重启后不会把旧日志全部载入窗口，可通过资源管理器打开文件。

更改桌面位置不改变日志目录。修改 Log 路径不移动、复制或删除旧日志；已经执行中的命令和已经打开的 GUI 终端继续写入原日志直到结束，新操作使用新目录，避免把同一操作的前后输出拆散。断开、切换服务器或正常退出时尝试排空写入队列并关闭日志。旧服务器的迟到回复不会写入新服务器。

## GUI 终端与记录边界

GUI 终端记录实际 SSH 启动命令、发送的原始输入与服务器回复，并用相同 operationId 关联及逐条标注时间。方向键、控制字符、Vim/htop 输入按原样记录，不猜测重建 shell 最终执行的命令。第三方通过 SSH exec 执行的非交互命令保存完整原文。实时监听默认“系统操作”，另有“第三方访问”和“虚拟终端”两个独立标签；切换标签不会停止后台记录。

SFTP 文件操作记录协议、操作类型、路径和结果，不伪称执行过 `cp`、`mv` 等 shell 命令。系统日志不保存 Monaco 文档全文和编辑按键、网页 DOM、Cookie、登录表单中的 SSH 密码、私钥内容或实例认证令牌；URL 仅保存协议、主机和路径，去掉账号密码、查询串和片段。用户主动写在命令、Notebook 代码或服务器输出中的内容会按操作历史保存。GUI 终端是原始转录：手动输入的密码、令牌以及终端编辑器按键也可能进入日志，请按敏感文件管理日志。

服务器时间与系统查询使用操作摘要；时钟连接时校准一次，之后按本机时间差推进，不循环发送查询指令。窗口移动、缩放及纯界面焦点切换不生成远程命令日志。工作台保存包含路径、字节数和成功/失败摘要；Notebook 包含用户执行代码及输出。系统日志记录应用操作，不审计绕过本应用建立的 SSH 连接。摘要作用域使用 AsyncLocalStorage 绑定单次 GUI 操作，不会抑制同时进行的第三方或终端访问。

## 写入失败与权限

新建日志使用独占文件名；应用默认目录 `~/.rdesktop/log` 权限设为 0700，文件为 0600，依赖服务器执行当前账号权限。用户选择的自定义日志目录保留其已有目录权限，应用不将公共目录改为 0700。拒绝以符号链接作为日志目录，不覆盖既有日志。日志包含操作内容，应按当前账号的数据进行管理。

日志目录不可写、磁盘不足、SFTP 超时或断网时，通知/监听窗口显示具体日志错误，应用操作仍可继续；不要把此状态视为已完整落盘。排队数据达到 32 MiB 时停止当前日志上下文的写入并提示，避免占满应用内存。解决问题后重新连接可创建新日志。强制结束进程或网络突然中断可能留下不完整的最后一行或尚未写入的尾部记录，本功能不提供不可篡改审计或断线后的持久补传。

## 验证范围

使用隔离的 Windows Electron 进程、本地命名管道和真实回环 SSH/SFTP 测试服务器验证通知、指令回复、日志落盘及分离、GUI 终端转录和浏览器遮挡处理。1.1.12 增加三个分类的交互、键盘切换、GUI 成功/失败摘要与原始终端/CLI 分离测试，以及并发操作不会串用摘要作用域的测试。继续覆盖 In/Out 聚合、Shell/ANSI 显示、输出 HTML 注入防护、自定义日志目录、跨服务器隔离和已有终端切换日志目录后的连续性。日志模块另覆盖轮换、只读目录、符号链接、连接切换、队列上限和超时。未连接用户生产服务器；Linux 文件模式的实际强制执行及生产网络异常需要在目标服务器环境验证。完整结果以本版交付记录为准。
