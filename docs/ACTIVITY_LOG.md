# 本地 CLI 监听与操作日志

适用于 Remote Desktop App 1.1.3。

## 连接通知与实时查看

通过 [CLI](CLI.md) 向指定桌面实例执行 `exec`、`upload`、`download` 或 `cancel` 后，桌面右下角显示“检测到本地命令行连接”、IP 来源和连接时间。认证成功的实际请求自动开始记录；无需先点击按钮。`connect` 在连接结果确定后显示通知。`list`、`status`、`focus` 用于发现、检查或唤起实例，不产生操作会话和重复通知。

点击通知中的“实时监听”，或顶栏活动图标，可打开监听窗口。它显示发送的命令、工作目录、stdout/stderr、传输进度及最终结果；非零退出码、错误和取消会保留在记录中。可选择历史会话，关闭自动滚动，拖动、缩放、最小化或关闭窗口。重复打开只恢复同一个窗口；关闭窗口不会停止记录。左侧动态窗口标签可恢复最小化窗口。

每次 CLI 调用使用一次经过实例令牌认证的本地 IPC 连接，对应一个日志会话。Windows 使用命名管道，它没有 TCP 来源 IP；应用不会把客户端自行提交的地址视为来源。若能从已有 SSH 连接取得本机出口地址，会显示为“IP：…（SSH 本机出口地址）”；否则显示“本机命名管道（无网络 IP）”。这不是服务器地址，也不能据此区分同一账号下的本地进程。连接时间使用 ISO 8601 UTC 存储，界面按本机时区显示并标注时区。

## 文件位置与内容

连接并确认远程桌面目录后，在**服务器当前桌面目录**自动创建 `.log`。例如桌面为 `/home/user/rdesktop`，则日志在 `/home/user/rdesktop/.log/`。这是隐藏目录，可开启资源管理器的“显示隐藏文件”，或直接在地址栏输入完整路径。监听窗口显示日志文件的完整路径。

| 文件 | 内容 |
| --- | --- |
| `cli-时间-随机标识.log` | 一次本地 CLI 连接的元数据、命令及参数、流式回复、传输进度、退出码或错误 |
| `system-时间-随机标识.log` | GUI 文件导航和操作、权限检查、文档及 Notebook 操作、浏览器导航/下载摘要、GUI 终端启动命令与服务器输出转录、连接和桌面切换 |

系统日志对 CLI 仅写 `cli-connection`，字段为 `type`、`time`、`ip`、`logPath`，不重复保存 CLI 命令、输出或传输参数。CLI 日志轮换时增加指向新分卷的索引。文件为 UTF-8，每行一个 JSON 对象（NDJSON），可用工作台只读查看或下载后处理。

日志以 8 MiB 为目标，在完整 JSON 记录之间轮换为 `.part002.log` 等分卷，单条超大记录可能让一卷超过该值。旧卷不会自动删除。远程日志保存完整已接收记录；实时窗口仅保留最近 100 个会话、600 条记录和约 2 MiB 内容，单个字段显示最多 32768 字符。应用重启后不会把旧日志全部载入窗口，可通过资源管理器打开文件。

更改桌面位置后，新操作写入新桌面的 `.log`；正在运行的 CLI 会话继续写原文件。断开、切换服务器或正常退出时尝试排空写入队列并关闭日志。旧服务器的迟到回复不会写入新服务器。

## GUI 终端与记录边界

GUI 终端记录实际 SSH 启动命令、服务器 PTY 输出和退出结果，包括正常 shell 回显的命令，以及 Vim 保存/丢弃关闭指令。它属于终端转录，不是解析后的 shell 历史：全屏程序、光标移动、退格或关闭回显会影响显示内容。不会逐键记录 `terminalInput`，因此关闭回显时输入的密码不会因本地键盘记录而泄露；服务器主动输出的内容仍会进入转录。

SFTP 文件操作记录协议、操作类型、路径和结果，不伪称执行过 `cp`、`mv` 等 shell 命令。系统日志不保存文档全文、每次编辑按键、网页 DOM、Cookie、SSH 密码、私钥或实例认证令牌；URL 仅保存协议、主机和路径，去掉账号密码、查询串和片段。用户主动写在命令、Notebook 代码或服务器输出中的内容会按操作历史保存。

自动时钟刷新、窗口移动/缩放及纯界面焦点切换不生成远程命令日志。工作台保存包含路径、字节数和成功/失败摘要；Notebook 包含执行代码及输出。系统日志记录应用操作，不审计绕过本应用建立的 SSH 连接。

## 写入失败与权限

新建日志使用独占文件名；`.log` 权限设为 0700，文件为 0600，依赖服务器执行当前账号权限。拒绝把 `.log` 符号链接作为日志目录，不覆盖既有日志。日志包含操作内容，应按当前账号的数据进行管理。

桌面只读、磁盘不足、SFTP 超时或断网时，通知/监听窗口显示具体日志错误，应用操作仍可继续；不要把此状态视为已完整落盘。排队数据达到 32 MiB 时停止当前日志上下文的写入并提示，避免占满应用内存。解决问题后重新连接可创建新日志。强制结束进程或网络突然中断可能留下不完整的最后一行或尚未写入的尾部记录，本功能不提供不可篡改审计或断线后的持久补传。

## 1.1.3 验证范围

使用隔离的 Windows Electron 进程、本地命名管道和真实回环 SSH/SFTP 测试服务器验证通知、指令回复、日志落盘及分离、GUI 终端转录和浏览器遮挡处理。日志模块另覆盖轮换、只读目录、符号链接、连接切换、队列上限和超时。未连接用户生产服务器；Linux 文件模式的实际强制执行及生产网络异常需要在目标服务器环境验证。
