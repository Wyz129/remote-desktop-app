# Monaco Editor

Monaco Editor 由主进程读取和保存远程文件，渲染器只接收当前文档内容。Monaco 提供 Python、C/C++、Fortran、HTML、JavaScript、CSS、JSON、Markdown 和 Shell 的语法高亮、行号、折叠、搜索替换；保存使用远程文件版本摘要检测冲突。远程文件被其他程序修改时不会覆盖，窗口会保留当前内容，可重新载入或另存为。

`.ipynb` 使用 nbformat 4。Markdown 公式由 KaTeX 渲染，已有输出按文本、HTML 和受限图片显示；脚本、外部图片、SVG、Widget、二进制通道和 stdin 交互输出会被过滤或提示不支持。连接 Jupyter 时填写服务器已启动的 HTTP(S) 根地址和 Token，所有 REST/WebSocket 请求通过当前 SSH 的 `forwardOut` 发出，域名由服务器解析。工作台可以查看 kernelspec、启动/连接内核、执行、中断、重启和关闭；不会自动安装或启动 Jupyter。

HTML 提供源码、预览和分栏模式。预览默认只开放 HTML 所在目录的已保存资源；可在“预览资源目录”中明确指定上层项目目录来支持相对 `../` 引用。预览 iframe 只有 `allow-scripts`，无 preload、Node、应用 IPC 或文件接口；主进程网络拦截只允许当前一次性资源令牌。需要访问外部网站时使用隔离服务器网络浏览器。

打开文件前检查当前 SSH 账号的实际读写权限。只读文件可搜索、复制和另存为；关闭、切换连接或退出时会通过原生对话框选择保存、丢弃或取消。断开连接后窗口保留未保存内容并进入只读状态。文档最大 16 MiB，要求有效 UTF-8；二进制或更大文件请使用 Vim 或传输中心。

左侧 Monaco Editor 快捷方式打开未命名文本；Ctrl+S 会要求输入服务器上的新路径，文件必须尚不存在。工具栏“打开”接受远程绝对路径，切换前检查未保存修改。新文档关闭时可返回另存为、丢弃或取消。终端不再参与普通文本与脚本文件的默认打开流程；需要 Vim 时可在终端自行运行。
