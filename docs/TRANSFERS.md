# 传输中心

顶栏传输图标打开面板。顶部仅提供上传和下载，下面展示本次及历史传输。

## 上传与下载

- 上传：直接打开 Windows 原生文件选择窗口，可用 Ctrl/Shift 多选文件或输入文件路径，点击“选择文件”后立即进入服务器虚拟资源管理器选择目标目录。无需返回应用确认本机选区；不支持上传文件夹。
- 下载：先在虚拟资源管理器中 Ctrl 多选服务器文件/文件夹，再选择本机保存目录。可以双击进入目录或在路径框中直接输入完整路径。
- 将远程文件/文件夹拖入传输面板或顶栏传输按钮，直接选择本机目录。
- 将本机文件拖入虚拟桌面，直接选择服务器目录；若混入文件夹则拒绝整批选择并明确提示，不会仅上传其中部分文件。浏览器网页使用独立隔离视图，网页内的拖放由网站处理，请拖到桌面或传输面板。

选择过程中可取消；连接切换后忽略尚未关闭的原生窗口返回的旧选择，避免把旧账号的文件送到新服务器。界面上传拒绝文件夹、符号链接、目录联接和特殊文件；选中文件在上传前被替换为目录时也会拒绝。权限、自动协议选择、同名不覆盖与此前相同，见 README。

本机文件选择使用 Electron 的 `dialog.showOpenDialog`，由 Windows 提供原生窗口。已移除应用自制确认浮窗以及 PowerShell/Shell COM 选区读取脚本；不需要额外选择器程序。

## 历史与目标目录

上传、下载、网页及本地 CLI 传输共享历史。活动任务显示进度及取消按钮；完成、失败或取消后隐藏这些控件，并提供“删除记录”。“清空历史”仅清理已结束记录，所有文件保留。

完成记录的“打开目标目录”会打开对应的 Windows 或虚拟资源管理器。服务器目标必须匹配当前主机、端口、账号及主机指纹；不匹配时提示先连接对应服务器。

历史保存在 Electron 用户数据目录下的 `transfer-history.json`，最多保留 500 条。启动时把上次未结束的任务标为失败，并提示检查目标，不自动继续或重试。历史读取、写入失败均会报告。网页下载到服务器的记录定位服务器目标目录，不会定位本机临时目录。

## 支持范围

原生窗口支持当前目录内多个文件，跨目录文件可分批上传。服务器选择框一次输入一个路径，多选通过当前目录的列表完成。目录下载仍可用；高级 CLI 的 `upload` 命令继续支持目录递归上传，见 [CLI 使用说明](CLI.md)。传输不保留权限、所有者和时间戳；不承诺断点续传。错误、取消、断网和同名处理详见 README 与浏览器下载说明。
