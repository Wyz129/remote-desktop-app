# 传输中心

顶栏传输图标打开 **Transfer Center**，它与 Settings 一样是桌面内的独立窗口，可拖动、缩放、最小化、最大化，并从左侧运行图标恢复；重复打开只聚焦现有窗口。关闭窗口不取消正在进行的传输。左侧“任务”显示默认目录与正在传输的项目；“历史记录”显示已完成、已取消或失败的项目。“高级设置”打开 Settings 的“文件与传输”分类。

## 上传与下载

- 上传：将 Windows 中的文件拖入桌面或 Transfer Center，再用服务器虚拟资源管理器选择目标目录；不支持上传文件夹。
- 下载：在虚拟资源管理器中选择服务器文件/文件夹，通过右键“下载到本地”选择本机保存目录，也可拖入 Transfer Center。
- 将远程文件/文件夹拖入传输面板或顶栏传输按钮，直接选择本机目录。
- 将本机文件拖入虚拟桌面，直接选择服务器目录；若混入文件夹则拒绝整批选择并明确提示，不会仅上传其中部分文件。浏览器网页使用独立隔离视图，网页内的拖放由网站处理，请拖到桌面或传输面板。

选择过程中可取消；连接切换后忽略尚未关闭的原生窗口返回的旧选择，避免把旧账号的文件送到新服务器。界面上传拒绝文件夹、符号链接、目录联接和特殊文件；选中文件在上传前被替换为目录时也会拒绝。权限、自动协议选择、同名不覆盖与此前相同，见 README。

任务页不再显示“上传”“下载”按钮；本机保存目录使用 Windows 原生窗口，服务器目录使用虚拟资源管理器。网页区域由网站处理拖放，应用内其他区域仍按文件来源触发上传或下载。

在 Transfer Center 的任务页可直接输入或浏览选择“服务器上传目录”与“本地下载目录”，按“保存目录”后生效；也可在“Settings → 文件与传输”修改。服务器字段表示从本机上传文件的默认目标，初始为 `~/.rdesktop/download`，界面显示实际绝对路径。本机字段初始显示 Windows 下载目录。上传选择目标时从默认上传目录打开；本机保存对话框、浏览器下载保存框从默认下载目录打开，用户仍可临时选择其它位置。不指定下载目标的本地 CLI 下载也使用此默认下载目录。留空恢复上述默认目录。新上传目录须为当前服务器可访问的绝对路径；本机目录须存在，保存失败会保留之前的设置。

默认上传目录按服务器主机、端口、账号和已验证主机指纹分别保存，切换服务器后读取对应路径，断连时不暴露上一账号的上传目录。默认下载目录是本机全局偏好。两者保存于本机用户数据，不向服务器写入应用设置文件。服务器网页下载未另选位置时使用 `~/.rdesktop/download`，它与本机默认下载目录不同。

## 历史与目标目录

上传、下载、网页及本地 CLI 传输共享历史。活动任务显示进度及取消按钮；完成、失败或取消后自动移到“历史记录”，隐藏这些控件，并提供“删除记录”。“清除已结束记录”仅清理已结束记录，所有文件保留。在任务或历史页面拖入本机文件都会进入上传流程，拖入服务器文件或目录则进入下载流程。

完成记录的“打开目标目录”会打开对应的 Windows 或虚拟资源管理器。服务器目标必须匹配当前主机、端口、账号及主机指纹；不匹配时提示先连接对应服务器。

历史保存在 Electron 用户数据目录下的 `transfer-history.json`，最多保留 500 条。启动时把上次未结束的任务标为失败，并提示检查目标，不自动继续或重试。历史读取、写入失败均会报告。网页下载到服务器的记录定位服务器目标目录，不会定位本机临时目录。

## 支持范围

拖放可同时上传多个普通文件。服务器选择框一次输入一个路径，多选通过当前目录的列表完成。目录下载仍可用；高级 CLI 的 `upload` 命令继续支持目录递归上传，见 [CLI 使用说明](CLI.md)。传输不保留权限、所有者和时间戳；不承诺断点续传。错误、取消、断网和同名处理详见 README 与浏览器下载说明。
