# 视频播放器

Remote Desktop App 1.1.7 使用 Apache-2.0 许可的 Video.js 8.24.1，播放器、中文语言包、样式和许可证随软件离线打包。

连接 SSH 后，从侧栏底部的“工具箱”打开“视频播放器”，点击“打开视频…”并在虚拟资源管理器中选择服务器文件。也可直接双击视频文件。播放器在虚拟桌面内显示，支持拖动、调整大小、最小化、最大化与关闭。Video.js 提供播放/暂停、进度拖动、音量、倍速及全屏。空格或 K 播放/暂停，左右键前后跳转 5 秒。

## 支持范围

- 支持 MP4、M4V、WebM、OGV、OGG 和 MOV 容器。具体音视频编码由当前 Electron/Chromium 决定；容器支持不代表所有编码都能解码。
- 视频从现有 SSH/SFTP 连接按需读取，支持 HTTP Range 跳转，无需先下载整个文件；不在服务器安装播放器或转码器。
- 不支持的容器、编码、损坏文件、权限错误和连接中断会明确显示错误。可下载原文件后使用 VLC 等本地播放器。当前没有服务器转码、HLS/DASH、直播、DRM、外部字幕或网络媒体 URL 功能。
- 文件须为普通文件，大小 8 字节至 8 TiB；最多同时打开 16 个媒体。文件的大小、修改时间、权限或路径变化后，旧播放地址会失效，需要重新打开。

## 数据与权限

主进程通过当前 SSH 账号读取文件。渲染器只收到一个临时的本机回环媒体地址；地址限于单个已选文件，只接受读取及范围读取，不能执行命令或操作其它文件。页面没有 SSH 凭据。媒体使用分块流和背压，不把整个视频读入内存；关闭播放器、切换或断开连接会撤销对应地址并停止传输。临时地址只在当前应用运行期间有效，不应复制到网页或外部应用。

## 实际验证

模块测试通过隔离回环 SSH/SFTP 检查范围读取、权限、路径/格式校验、文件变化、取消及断连。真实 Electron 测试使用 Chromium 生成的原创 VP8 WebM，验证实际播放、暂停、seek 和销毁；这不代表已验证所有编码或用户服务器的网络环境。完整主应用及打包验收结果见 [1.1.7 交付记录](RELEASE-1.1.7.md)。
