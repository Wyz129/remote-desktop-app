# 服务器网络浏览器

浏览器窗口的可信工具栏与远程网页分离。网页 WebContents 没有 preload、Node、`window.remoteDesktop` 或文件操作接口；禁止弹窗、权限请求、`file:` 和自定义协议。HTTP(S) 与 WebSocket 通过当前 SSH 连接建立，SOCKS5 转发把目标主机名交给服务器解析，`localhost` 指服务器自身。每个连接使用独立 session partition，断开时清理 Cookie、缓存和代理通道。

网页下载沿用该页面的 Cookie、POST 登录态和 Blob 响应。工具栏可选择保存到本机，或先写入本机暂存文件再上传到服务器指定目录。任务进度、取消、错误和最终路径出现在传输中心；本地目标使用独占创建，不覆盖已有文件。取消、失败和断开会删除本机暂存内容并尝试停止网页任务。DRM、File System Access、后台特殊下载、需要浏览器扩展的下载方式不在支持范围内，页面应提供普通直接下载链接。

HTML 文档的预览使用工作台的受限资源服务，适合查看服务器项目内相对 CSS、图片和 JavaScript；它不提供外部联网能力。浏览器功能需要活动 SSH 会话，连接切换会关闭旧窗口和其登录态。
