# 浏览器

连接 SSH 后，点击顶栏浏览器图标，或侧栏底部“工具箱”中的“浏览器”，打开虚拟桌面内的浏览器窗口。窗口支持移动、调整大小、最大化、最小化和关闭；同一连接重复点击图标会聚焦已有浏览器。浏览器内网页请求的新窗口、`target="_blank"` 链接和表单会打开为新标签页，并自动聚焦新标签页。标签栏支持切换、关闭和新建；关闭最后一个标签页会关闭浏览器窗口，不会关闭虚拟桌面。

浏览器窗口的可信工具栏与远程网页分离。网页 WebContents 没有 preload、Node、`window.remoteDesktop` 或文件操作接口；禁止权限请求、`file:` 和自定义协议。弹窗标签沿用隔离网页的会话与安全设置，保留原始 POST 与 referrer。HTTP(S) 与 WebSocket 通过当前 SSH 连接建立，SOCKS5 转发把目标主机名交给服务器解析，`localhost` 指服务器自身。每个连接使用独立 session partition，断开时清理 Cookie、缓存和代理通道。

网页下载沿用该页面的 Cookie、POST 登录态和 Blob 响应。工具栏可选择保存到本机，或先写入本机暂存文件再上传到服务器指定目录。任务进度、取消、错误和最终路径出现在传输中心；后台标签页发起的下载同样保留。下载到本地时使用 Windows 保存对话框，本地目标使用独占创建，不覆盖已有文件。取消、失败和断开会删除本机暂存内容并尝试停止网页任务。DRM、File System Access、后台特殊下载、需要浏览器扩展的下载方式不在支持范围内，页面应提供普通直接下载链接。

HTML 文档的预览使用工作台的受限资源服务，适合查看服务器项目内相对 CSS、图片和 JavaScript；它不提供外部联网能力。浏览器功能需要活动 SSH 会话，连接切换会关闭旧浏览器与其标签页和登录态。

浏览器原生网页层会在工具箱、设置、选择器、菜单或其他虚拟窗口覆盖它时隐藏；重新聚焦浏览器后恢复。该处理让桌面弹窗和资源管理器保持可操作，不会重载网页或清除标签页状态。

测试使用隔离 Electron、回环 SSH 服务与受控 HTTP 服务，覆盖远程 DNS、localhost 转发、Cookie/POST/Blob 下载、目标冲突、取消/中断、隔离接口、标签与弹窗 POST、后台下载、嵌入窗口布局和关闭/断开清理。没有使用用户服务器或真实第三方网站凭据。
1.1.7 起，网页下载选择保存到服务器时，默认目录为 `~/.rdesktop/download`，自动初始化且不随桌面位置变化；保存到本机仍使用系统“下载”目录。
