# 服务器压缩与解压

适用于 Remote Desktop App 1.1.12。所有压缩与解压在当前 SSH 服务器上完成，源文件不会先下载到本机。需要服务器 `PATH` 中已有 **Python 3.8 或更新版本**，仅使用 `tarfile`、`zipfile` 等标准库；应用不会自动安装 Python 或其它依赖。

## 操作

在桌面或虚拟资源管理器的同一目录中选择文件/文件夹，右键“压缩…”，在原生对话框选择 `.tar.gz` 或 `.zip`。可多选，压缩包保存在当前目录：单个项目使用其名称，多选使用 `Archive`；同名时创建 `名称 (2).扩展名` 等新文件，不覆盖已有项目。

选择一个 `.zip`、`.tar.gz`、`.tgz` 或 `.tar` 文件，右键“解压缩”。应用先检查成员，再在压缩包所在目录建立新的独占文件夹，使用去掉归档后缀的名称；同名自动编号。归档内的路径结构保留在该文件夹中，不与当前目录或已有目标合并。暂不支持 RAR、7z、加密归档、分卷或原地覆盖解压。

取消格式选择不会开始压缩；开始后由现有文件操作流程显示成功或具体错误，并刷新相应目录。结果同时进入“实时监听 → 系统操作”，不展示内部 Python 实现。当前没有归档专用进度条、暂停或断点续传。

## 路径、容量与权限

- 一次最多选择 1000 个同目录的直接子项目；归档最多 100000 个文件/目录，源数据或声明的解压总量最多 100 GiB。单次操作截止时间为 15 分钟。
- 源项目只接受普通文件与目录。符号链接、硬链接归档成员、设备节点和其它特殊文件不支持；提取不使用不受限的 `extractall`。
- 拒绝绝对路径、`..`、反斜杠/盘符等不安全成员名，以及重复成员、同路径文件与目录或父子文件冲突。提取按实际读取字节验证声明大小，损坏或截断包报错。
- 所有读取与新建都受当前服务器账号权限约束；提取前检查声明大小与目标磁盘可用空间。不会使用 sudo，不修改原文件或已有输出。没有权限、空间不足或缺失 Python 会显示错误。
- 主要保证普通文件内容与目录结构，不承诺保留所有者、ACL、扩展属性或完整时间戳/权限信息。压缩源在扫描后变化可能使操作失败，应使用稳定的源数据。

正常 Python 异常会尝试删除本次新建的失败输出。断网、SSH 超时、应用强制退出或远程进程中止时，不能保证远程清理已经执行；请检查源目录中的本次新归档/新文件夹，确认后再处理未完成内容。新输出在执行过程中可能已经可见，收到成功结果前不要作为完整归档使用。

## 实际验证范围

`npm.cmd run test:archives` 的 10 个场景通过，使用真实回环 SSH/SFTP 加隔离本机 Python，验证 tar.gz/zip 往返、二进制字节、空目录、同名不覆盖、含中文/引号的路径、恶意成员与损坏归档拒绝、无 Python 和权限失败，以及目录别名、成员上限、失败清理、源文件变化、SSH 会话切换和输出校验。没有用用户服务器执行测试，未以真实 100 GiB 或 100000 项数据做性能验收，也未验证所有第三方生成器的归档变体。最终 GUI 与打包验证见 [1.1.12 交付说明](RELEASE-1.1.12.md)。
