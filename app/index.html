桌面外观

可选择服务器上任意有访问权限的目录作为桌面，名称不限；位置会为当前服务器账号保存。

应用设置

小文件通过 SSH 命令流下载，达到阈值使用 SFTP；SFTP 同样基于 SSH。文件只在编辑器中打开，不会自动运行。

原 VS Code 命令快捷方式会被跳过；文件符号链接和固定终端继续可用。
