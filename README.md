# Remote Desktop App

通过 SSH 连接 Linux/类 Unix 服务器的独立桌面应用，版本 1.1.11。应用使用 Electron 44.4.2，提供 Monaco Editor、浏览器、双向传输中心与本地命令行接口，无需 VS Code、Remote-SSH 扩展或服务器端桌面软件。现有资源管理器、文件操作、Vim 和 xterm 终端继续保留。

独立应用仓库为私有的 [Wyz129/remote-desktop-app](https://github.com/Wyz129/remote-desktop-app)。它由原扩展 0.0.7 的提交 `8c2e415f41759dca41d632c855347d539180e6ca` 克隆开发，保留迁移历史；插件仓库 `Wyz129/remote-desktop` 独立维护。本地工作目录为 `C:\0_myfiles\new_projects\remote-desktop-app`；旧 `upstream` 推送地址保持禁用，新仓库使用 `origin`。

## 启动

在 Windows PowerShell 中执行：

```powershell
Set-Location 'C:\0_myfiles\new_projects\remote-desktop-app'
npm.cmd ci
npm.cmd start
```

开发环境使用 Node.js 24 和 npm；首次安装/启动需要下载 Electron。启动脚本自动从子进程环境移除 `ELECTRON_RUN_AS_NODE`，不会修改系统环境。`npm.cmd run dev` 启用 Electron 日志，不应将密码或私钥加入日志。

本机可运行程序：`artifacts/electron-1.1.11/win-unpacked/Remote Desktop.exe`。直接双击即可，无需 Node.js 或 VS Code；请保留同目录全部文件。这是未签名的 Windows x64 展开目录，GitHub 仓库包含源码，不包含安装器。命令行入口位于同目录的 `resources/cli/scripts/rdesktop.cmd`，同样无需额外 Node.js。

启动后显示 Ubuntu 风格的居中头像和用户名、密码两个输入框；输入后按 Enter 或点击密码框右侧箭头登录。下方“切换账号”进入服务器配置界面，可选择已保存服务器，或点击“新建”设置地址、端口（默认 22）、用户名、别名和本地私钥。可直接“连接服务器”，也可“保存配置”后返回登录页；左上角返回箭头同样返回登录页。切换、返回和保存时清空密码及私钥口令；已配置私钥时登录页额外提供私钥口令输入。配置只保存地址、端口、用户名、别名和私钥路径，不保存密码或私钥内容。连接成功后窗口标题显示 `Remote Desktop - ssh 用户名@服务器IP:端口 别名`。

首次连接弹出系统原生主机密钥核验窗口，显示 SHA-256 指纹；确认后才继续认证并保存该主机与端口的指纹。以后连接必须匹配已保存的指纹，变化时明确拒绝。请使用从服务器管理员处获得的指纹核对。应用不会自动安装远程软件。

全屏可通过顶栏全屏图标、F11 或 Ctrl+Alt+F 切换；Esc 退出全屏。顶栏右侧显示“用户名·已连接”，“切换账号”按钮打开当前连接面板；已连接时显示账号文本及“断开、重新连接、切换账号”。重新连接需重新输入本次认证信息；切换账号进入服务器配置界面，在提交新的登录前保留现有连接。关闭应用会结束 SSH 和该应用打开的远程终端。

1.1.11 增加资源管理器目录侧栏与标题栏面包屑、分类传输中心、原始指令 In/Out 监听、可配置顶栏及时间通知面板。整体沿用炭灰内容区、灰紫文件夹和低饱和度棕橙选中态。窗口控件平时透明，仅悬停显示背景，键盘焦点仍有轮廓。浏览器未被遮挡时保持原生实时页面，重叠时显示约每 0.75 秒更新的背景预览，聚焦后恢复完整交互。详见 [1.1.11 交付说明](docs/RELEASE-1.1.11.md)；此前的程序网格与浏览器布局见 [1.1.10 交付说明](docs/RELEASE-1.1.10.md)。

## 远程桌面与文件

认证后读取真实 `$HOME`，自动初始化 `~/.rdesktop/desktop`（默认桌面）、`~/.rdesktop/log`（操作日志）、`~/.rdesktop/download`（网页保存到服务器的默认目录）和 `~/.rdesktop/trash`（Trash 入口默认目录）。1.1.7 首次启动忽略旧版本的桌面路径偏好，不移动、删除或复制旧桌面内容。新版中在设置重新选择任意可访问目录后，会按主机、端口、账号和已验证指纹保存，后续重连和重启仍恢复。日志与默认服务器下载路径不随桌面位置变化。若目录创建失败或存在同名文件/符号链接，显示具体路径及错误；仍可通过 Home/设置处理可访问的目录。

- 双击文件夹打开资源管理器；目录快捷方式成功打开后，地址栏与导航历史显示实际目标目录。窗口内双击子目录在该窗口导航。地址栏支持绝对路径、`~`、`~/目录` 和相对路径。
- 左侧固定 Root、Home、Desktop、Log、Trash；“设置 → 目录与侧栏”可调整 Log、Trash 路径，添加文件夹快捷方式及重新排序，Desktop 路径在“桌面与外观”设置。这些远程目录偏好按服务器身份隔离。Trash 目前是普通目录入口，删除操作仍为确认后的永久删除。
- 标题栏中央显示可点击的路径分段，空间不足时优先保留当前目录及附近父目录。点击路径空白处、省略号，或按 Ctrl+L / F4，可编辑完整路径；Enter 跳转、Esc 取消。详见 [资源管理器说明](docs/EXPLORER.md)。
- 窗口可拖动、八方向缩放、最大化、还原、最小化；左侧任务栏恢复最小化窗口。可同时打开多个目录、终端和图片窗口。
- 右键菜单包含新建文件/目录、重命名、复制、剪切、粘贴、删除、创建桌面符号链接、下载、终端和刷新。保留 Ctrl 多选、框选和跨窗口文件移动。
- 新建默认名为 `New File.txt`、`New Folder`，Enter 提交、Esc 取消；冲突生成编号名称。移动或重命名不会静默覆盖已有项目。永久删除必须在原生确认窗口中确认；删除符号链接只删除链接本身。
- 资源管理器可浏览 `/` 起的整个文件系统及外部符号链接，由服务器授予当前账号的权限决定访问与修改能力。目录访问失败保留上一个成功位置、内容和历史，同时显示“无访问权限”、请求路径及具体错误。登录主目录、当前桌面根目录、`/` 及其上级目录不能整体移动、重命名或删除。隐藏文件仍可通过设置显示。
- F5 刷新，F2 重命名，Delete 请求删除，Ctrl+C/X/V 复制、剪切和粘贴。快捷键作用于应用内当前区域。

普通文本或脚本统一在虚拟桌面内部的 Monaco Editor 窗口打开，侧栏底部“程序”面板提供启动入口，支持新建未命名文档和打开远程文件。打开前通过当前 SSH 账号检查实际读写权限；无法读取时显示“无访问权限”，可读但不可写时显示“无编辑权限”，可选择只读打开。实际操作仍受服务器权限约束。压缩包、ODB、办公文档等常见二进制文件提示下载后处理。Vim、htop 必须已安装在服务器 PATH 中，缺失时终端明确报错。

## Monaco Editor、Notebook 与 HTML

文本编辑使用微软 MIT 开源的 [Monaco Editor 0.53.0](https://github.com/microsoft/monaco-editor)，即 VS Code 的编辑器组件，非自行仿制。Monaco 提供行号、折叠、搜索替换与撤销重做；应用补充 SSH 远程保存及 Fortran 语言规则，支持 Python、C/C++、Fortran 等语言高亮；支持 UTF-8 文本，单文档上限 16 MiB。关闭、重连和退出时询问保存、丢弃或取消。保存前比较远程内容版本，发现外部修改则保留编辑内容并拒绝覆盖，可重新载入或另存为；这不是服务器文件系统级并发锁。

`.ipynb` 支持 nbformat 4 单元格、Markdown、公式与已有输出，也可通过 SSH 连接已运行的 Jupyter 服务，执行代码并启动、连接、中断、重启或关闭内核。不会自动安装或启动远程 Jupyter。HTML 支持源码、预览、分栏；预览从服务器读取已保存版本及项目内相对 CSS、图片、JavaScript。默认资源范围为 HTML 父目录，可明确选择上层项目目录支持 `../` 引用。

具体操作、权限和支持边界见 [工作台说明](docs/WORKBENCH.md)。Notebook 富文本经过清理，HTML 预览使用独立沙箱；预览内不暴露 SSH、Node 或文件操作接口，外部联网请使用浏览器。

## 浏览器

从左栏底部“程序”打开浏览器，在虚拟桌面内显示浏览器窗口，可拖动、缩放、最大化、最小化与关闭。顶栏浏览器按钮默认隐藏，可在“设置 → 上栏与通知”启用。重复启动恢复已有窗口。网页的新窗口链接、`window.open` 和弹出表单进入新标签页并聚焦；关闭最后一个标签会关闭浏览器。HTTP(S)/WebSocket 通过现有 SSH 连接访问网络，域名由服务器解析；`localhost` 指服务器，可访问 Jupyter 等远程 Web 服务。网页与可信工具栏分开，网页无应用 IPC、文件操作或 SSH 凭据接口。

浏览器工具栏选择网页下载保存到本机或服务器。下载沿用当前网页会话的登录态，进度、取消、错误同步至传输中心；服务器保存先在本机暂存再通过 SSH 上传。断开 SSH 清除该浏览器会话的登录态。支持范围与特殊下载限制见 [浏览器说明](docs/BROWSER.md)。

顶栏默认依次提供切换账号、传输中心、实时监听、Home、设置、全屏、退出；可在“设置 → 上栏与通知”重新排序或隐藏，隐藏设置后仍可从“程序”打开。退出保留 Monaco 未保存文档确认。左侧收藏夹保留已打开窗口的动态标签和用户收藏的程序；栏内不常驻显示“收藏夹”或“程序”字样，底部九点图标的悬停提示为“程序”。点击打开类似 Ubuntu 的全桌面程序网格，提供浏览器、传输中心、实时监听、htop、Monaco Editor、图片查看器、视频播放器、Home、设置和终端。支持搜索、常用/全部切换、方向键导航、Enter 启动、Esc 关闭，启动后自动收起。右键图标或按 Shift+F10 可“添加到收藏夹”，再次右键可移除；收藏和启动次数保存在本机设置中，重启后恢复，不依赖某台服务器。离线仍可管理收藏，并打开设置、传输历史与监听记录。htop 需要已安装在服务器 PATH 中。Home 打开当前登录用户的真实主目录，已有窗口会恢复并聚焦；即使没有桌面目录，也能通过 Home 浏览公共资源。

## 实时监听与操作日志

本地 CLI 实际操作会在顶栏时间下方显示连接提示，监听自动开启。点击“实时监听”或顶栏活动图标可查看命令、流式回复和结果。监听按请求合并为 In/Out 块，使用本地 highlight.js 高亮 Shell、ansi_up 展示回复颜色，并用 DOMPurify 清理渲染内容。记录实际 SSH 指令、原始终端按键、stdout/stderr、结果及指令时间，不根据终端按键猜测最终命令；SFTP 操作显示真实协议元数据。服务器 `~/.rdesktop/log` 默认保存独立 CLI 日志与系统日志，可在“目录与侧栏”修改 Log 位置；旧日志不搬移，在途命令和已有终端继续写原日志至结束。系统日志对 CLI 仅保存连接时间、IP 来源和对应日志路径。日志权限、轮换、显示范围及写入失败说明见 [监听与日志说明](docs/ACTIVITY_LOG.md)。

## 图片查看器

图片查看器使用 MIT 许可的 [Viewer.js 1.14.0](https://github.com/fengyuanchen/viewerjs)，依赖和许可证随应用本地打包。可从侧栏底部“程序”面板启动后选择远程图片，也可双击 PNG、JPEG、GIF、WebP、BMP、AVIF 图片，在虚拟桌面窗口内查看；单图最大 25 MiB。图片初始适应窗口且不把小图强制放大。滚轮围绕鼠标指向的局部缩放，拖动平移；工具栏提供打开图片、放大、缩小、100%、适应窗口、旋转和水平翻转。图片窗口同样支持缩放、最大化、最小化和关闭。

SVG 不在图片查看器支持范围内；可下载原文件后使用适当应用打开。图像解码能力随 Electron/Chromium 版本而定。

## 视频播放器

视频播放器采用本地打包的 Apache-2.0 [Video.js 8.24.1](https://videojs.com/)。从“程序”启动后选择服务器文件，或直接双击视频文件，可在虚拟窗口播放、暂停、拖动进度、调节音量/倍速和全屏。视频通过现有 SSH/SFTP 按需读取，无需先下载整份视频或在服务器安装播放器。支持 MP4/M4V/WebM/OGV/OGG/MOV 容器，实际编码兼容性取决于 Electron；不支持的编码会明确报错，不自动转码。详见 [视频播放器说明](docs/VIDEO.md)。

## 传输中心与命令行

传输中心与设置共用分类布局，左侧为“任务”“历史记录”“高级设置”。任务页提供上传、下载及活动任务，完成后自动进入历史；高级设置直接打开设置的“文件与传输”，可配置默认上传目录（按服务器身份保存）及默认下载目录（本机全局）。上传直接在 Windows 原生文件选择框中多选文件，再用虚拟资源管理器选择服务器目标目录；下载顺序相反。服务器端支持 Ctrl 多选文件/目录、双击进入目录和直接输入路径。取消任一步都不会开始传输。详情见 [传输中心说明](docs/TRANSFERS.md)。

将远程文件/文件夹拖到传输中心直接选择本机目标目录；将本机文件拖入虚拟桌面界面直接选择服务器目标目录，若包含文件夹则明确拒绝整批上传。浏览器网页属于独立隔离视图，请把文件拖到桌面或传输中心，网页内拖放仍由网站处理。

对文件或目录右键选择“下载到本地”也会询问目标目录。CLI 未指定目标时使用设置中的本机默认下载目录，浏览器保存框也从该位置开始。未设置时取 Electron `app.getPath('downloads')`，跟随当前用户的系统 Downloads/下载文件夹设置，包括 Windows 已重定向路径，不硬编码用户名或 `C:\Users\...`。

| 对象 | 默认传输方式 |
| --- | --- |
| 小于 50 MiB 的单个文件 | SSH exec 的 `cat -- <安全引用路径>` 二进制流 |
| 大于或等于 50 MiB 的单个文件 | SFTP 流 |
| 目录及其所有文件 | 递归 SFTP |

**SFTP 本身基于 SSH**。这里区分 SSH 命令通道流与 SSH 的 SFTP 文件传输子系统。相同选择规则也用于文件上传；目录上传仅保留在高级 CLI 中，界面上传不支持文件夹。可在“设置 → 文件与传输”将阈值改为 1–1024 MiB 的整数，用于后续上传和下载。

顶栏传输图标打开传输中心，可以浏览服务器路径、选择本地保存目录、下载服务器项目，也可多选本地文件上传。任务显示进度、方式、错误和取消，包含网页及 CLI 发起的传输。任务结束后隐藏进度条和取消按钮；已结束历史可以逐条删除或清空，点击目标目录打开 Windows 或虚拟资源管理器。历史保存在本地 userData/transfer-history.json（最多 500 条），删除记录不会删除文件。服务器目标仅可在对应主机、账号及已验证指纹的连接下打开。同名文件或目录自动编号，已有目标不会被覆盖或合并。传输先进入独占临时目录，完整完成后才提交目标；正常取消或失败尝试清理临时内容。意外断网可能无法清理服务器暂存目录，错误会注明路径。目录总字节数先扫描，准备阶段也可取消。

服务器项目选择通过虚拟资源管理器完成：双击目录进入，Ctrl 多选项目后点“选择项目”，也可在底部路径框输入完整路径并回车。无法访问时显示具体错误。上传直接使用 Windows 原生文件选择窗口，支持 Ctrl/Shift 多选及输入文件路径；点“选择文件”后直接进入服务器目标目录选择，不再弹出应用确认小窗，不再调用 PowerShell 读取资源管理器选区。下载目标使用 Windows 原生目录选择窗口。

界面上传仅接受普通文件；所有上传均拒绝本地符号链接、目录联接及特殊文件，不保留权限、时间戳或所有者。CLI 目录上传保留内容和空目录。当前用户的本地命令行可启动/唤起实例、隐藏输入密码连接、复用实例上传/下载，或运行非交互远程命令并获得 stdout、stderr 和退出码。详见 [CLI 使用说明](docs/CLI.md)。

递归下载保留空目录。直接选择目录符号链接可下载它的内容；目录内部再遇到指向目录的符号链接会明确中止，以防循环，普通文件符号链接下载目标内容。特殊设备文件不支持。Windows 不允许的名称会安全替换，并处理保留名、大小写冲突；最多支持 128 层、100000 项的目录计划。

## 终端、设置和配置兼容

右键“在此处打开终端”或 Ctrl+Alt+T 在虚拟桌面中创建真实 SSH PTY，支持 Shell、Vim、htop。Ctrl+Alt+T 在当前应用内生效，优先采用聚焦目录；设置或连接对话框中不启动终端。最多 8 个终端，关闭窗口结束该会话，最小化保留会话。固定程序通过左侧终端标签右键保存；重新连接不会自动运行程序。

终端红叉、断开连接及退出应用时直接结束终端 SSH 会话，不再弹出保存提示，也不向终端注入 Vim 保存或退出指令。终端内手动编辑的内容请先在程序中保存。Monaco Editor 的未保存确认与冲突保护继续保留。

已有的 E325 交换文件可能含未保存内容，本版不会自动删除；应先在 Vim 中完成恢复或确认，再正常退出。

顶栏默认以简约格式显示服务器本地时间，可在“上栏与通知”改为包含秒和时区的详细格式；悬停始终显示时区，例如 `Asia/Shanghai (UTC+08:00)`。查询同时读取服务器 epoch、本地时间和实际偏移，优先识别 SSH 会话的 TZ，再查询系统时区；无法识别 IANA 时区名时使用服务器测得的偏移，不使用客户端时区。每 30 秒刷新，超过 90 秒未响应时提示等待服务器。点击时间打开通知与日历，历史自动滚动到最新；通知保留本次运行最近 200 条，清除不影响操作日志。提醒从顶栏时间下方向下滑入，系统启用减少动画时取消动画。

桌面设置含桌面位置、视图、背景、隐藏文件和应用下载阈值。仅选择路径不要求该目录可写；外观修改才写入远程配置，失败时明确保留已选路径并报告错误。桌面位置、应用设置和已知主机记录写入 Electron 当前用户的 `userData/settings.json`，不写入仓库。原 `remoteDesktopDemo.*` VS Code 设置不再作为独立应用的配置来源。

顶栏“设置”打开控制面板，整合虚拟桌面、应用设置、SSH 连接管理，以及 Ubuntu/Linux 的系统版本、CPU、内存、主目录磁盘、网络地址、时间、时区和语言信息。系统页是可刷新的只读快照；系统级变更仍在有相应权限的远程终端完成，不会自动执行 sudo。显示和声音等 Ubuntu 图形会话设置不属于 SSH 虚拟桌面。

设置采用左侧分类、右侧卡片布局，分为“桌面与外观”“文件与传输”“远程系统”“目录与侧栏”“上栏与通知”；分类支持方向键和 Home/End，切换时保留未提交字段。窗口控件与其它窗口统一，传输中心关闭按钮保持透明样式；设置和传输中心的内容按钮保留增强配色。设置支持拖动、缩放、最小化和最大化，同一时刻只存在一个设置窗口，再次点击只恢复并聚焦；较窄窗口内部滚动。

远程配置继续按下列顺序读取，首个存在的配置无效时显示错误，不悄悄跳过并覆盖：

1. `<Desktop>/.remote-desktop.json`
2. `<Desktop>/config.json`
3. `<home>/.config/remote-desktop/config.json`
4. `<home>/.remote-desktop.json`

配置上限为 64 KiB。未知字段保留；原 VS Code 命令快捷方式保留在 JSON 中，但在独立界面跳过，且不执行。固定 Shell/Vim/htop 和真实符号链接仍可使用。保存既有配置使用 OpenSSH 原子重命名扩展；服务器不支持时明确失败并保留原文件，不通过删除旧配置降级覆盖。
