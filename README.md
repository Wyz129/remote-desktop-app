# Remote Desktop App

通过 SSH 连接 Linux/类 Unix 服务器的独立桌面应用，版本 1.0.0。应用使用 Electron 44.4.2，无需 VS Code、Remote-SSH 扩展或服务器端桌面软件。现有虚拟桌面、资源管理器、文件操作和 xterm 终端继续保留。

本项目位于 `C:\0_myfiles\new_projects\remote-desktop-app`，由原扩展 0.0.7 的提交 `8c2e415f41759dca41d632c855347d539180e6ca` 克隆开发。原项目 `C:\0_myfiles\new_projects\remote-desktop` 和 GitHub `main` 保留；本副本分支为 `standalone-app`，上游远程名为 `upstream`，其推送地址已禁用。本阶段没有新建或发布 GitHub 仓库。

## 启动

在 Windows PowerShell 中执行：

```powershell
Set-Location 'C:\0_myfiles\new_projects\remote-desktop-app'
npm.cmd ci
npm.cmd start
```

开发环境使用 Node.js 24 和 npm；首次安装/启动需要下载 Electron。启动脚本自动从子进程环境移除 `ELECTRON_RUN_AS_NODE`，不会修改系统环境。`npm.cmd run dev` 启用 Electron 日志，不应将密码或私钥加入日志。

本机已生成可运行程序：`artifacts/electron/win-unpacked/Remote Desktop.exe`。直接双击即可，无需 Node.js 或 VS Code；请保留同目录全部文件。此版本为本地未签名的 Windows x64 原型，尚未创建安装器或发布。

启动后应用立即全屏，并显示 SSH 连接窗口。填写主机、端口（默认 22）、用户名和密码；也可使用“选择”按钮选取本地私钥，并按需要填写私钥口令。私钥由主进程读取，页面只提交所选路径。密码和私钥口令不写入应用设置。

首次连接弹出系统原生主机密钥核验窗口，显示 SHA-256 指纹；确认后才继续认证并保存该主机与端口的指纹。以后连接必须匹配已保存的指纹，变化时明确拒绝。请使用从服务器管理员处获得的指纹核对。应用不会自动安装远程软件。

全屏可通过顶栏全屏图标、F11 或 Ctrl+Alt+F 切换；Esc 退出全屏。顶栏插头图标可重新打开连接窗口或断开。关闭应用会结束 SSH 和该应用打开的远程终端。

## 远程桌面与文件

认证后在真实 SSH 登录环境读取 `$HOME`，再按优先顺序查找 `Desktop`、`desktop`、`桌面`（另接受大小写变体）。不写死账号，不使用本机主目录推断远程主目录，也不在失败时显示 Demo 文件。没有桌面目录会显示明确提示，只有点击“创建 Desktop”才新建目录。断连后清空当前远程内容和窗口。

- 双击文件夹打开资源管理器；窗口内双击子目录在该窗口导航。地址栏支持绝对路径、`~`、`~/目录` 和相对路径。
- 窗口可拖动、八方向缩放、最大化、还原、最小化；左侧任务栏恢复最小化窗口。可同时打开多个目录、终端和图片窗口。
- 右键菜单包含新建文件/目录、重命名、复制、剪切、粘贴、删除、创建桌面符号链接、下载、终端和刷新。保留 Ctrl 多选、框选和跨窗口文件移动。
- 新建默认名为 `New File.txt`、`New Folder`，Enter 提交、Esc 取消；冲突生成编号名称。移动或重命名不会静默覆盖已有项目。永久删除必须在原生确认窗口中确认；删除符号链接只删除链接本身。
- 文件浏览及修改限定在真实登录用户的主目录中，检查远程路径与符号链接目标。主目录、桌面根目录和 `/` 不能作为移动、重命名或删除目标。
- F5 刷新，F2 重命名，Delete 请求删除，Ctrl+C/X/V 复制、剪切和粘贴。快捷键作用于应用内当前区域。

普通文本或脚本文件在远程 Vim 窗口打开，只编辑，不自动执行脚本。压缩包、ODB、办公文档等常见二进制文件提示下载后处理；应用不解析这些格式。Vim、htop 必须已安装在服务器 PATH 中，缺失时终端明确报错。

## 图片查看器

双击 PNG、JPEG、GIF、WebP、BMP、AVIF 图片，在虚拟桌面窗口内查看；单图最大 25 MiB。图片初始适应窗口且不把小图强制放大。滚轮围绕鼠标指向的局部缩放，拖动平移；工具栏提供放大、缩小、100% 和适应窗口。图片窗口同样支持缩放、最大化、最小化和关闭。

SVG 不在图片查看器支持范围内；可下载原文件后使用适当应用打开。图像解码能力随 Electron/Chromium 版本而定。

## 下载到本地

对文件或目录右键选择“下载到本地”。默认目录来自 Electron `app.getPath('downloads')`，跟随当前用户的系统 Downloads/下载文件夹设置，包括 Windows 已重定向路径，不硬编码用户名或 `C:\Users\...`。

| 对象 | 默认传输方式 |
| --- | --- |
| 小于 50 MiB 的单个文件 | SSH exec 的 `cat -- <安全引用路径>` 二进制流 |
| 大于或等于 50 MiB 的单个文件 | SFTP 流 |
| 目录及其所有文件 | 递归 SFTP |

**SFTP 本身基于 SSH**。这里区分 SSH 命令通道流与 SSH 的 SFTP 文件传输子系统，并非两个互不相关的连接协议。50 MiB 是减少大文件命令通道传输的默认切换值，可在“桌面设置 → 应用设置”改为 1–1024 MiB 的整数；更改后用于后续下载。

顶栏下载图标打开任务面板，显示进度、使用方式和结果，支持多个任务及取消。同名文件或目录自动编号，已有本地内容不会被覆盖或合并。传输先进入应用创建的临时目录，完整完成后才提交目标；取消、失败或 SSH 断开会清理未完成的临时内容。目录总字节数先扫描再下载，准备阶段也可取消。若源文件大小在传输中改变，会报错要求重试。

递归下载保留空目录。直接选择目录符号链接可下载它的内容；目录内部再遇到指向目录的符号链接会明确中止，以防循环，普通文件符号链接下载目标内容。特殊设备文件不支持。Windows 不允许的名称会安全替换，并处理保留名、大小写冲突；最多支持 128 层、100000 项的目录计划。

## 终端、设置和配置兼容

右键“在此处打开终端”或 Ctrl+Alt+T 在虚拟桌面中创建真实 SSH PTY，支持 Shell、Vim、htop。Ctrl+Alt+T 在当前应用内生效，优先采用聚焦目录；设置或连接对话框中不启动终端。最多 8 个终端，关闭窗口结束该会话，最小化保留会话。固定程序通过左侧终端标签右键保存；重新连接不会自动运行程序。

顶栏账号、主机与时钟从服务器命令取得，时间以 UTC 显示；每 30 秒刷新，超过 90 秒未响应时提示等待服务器。它是 SSH 命令/心跳状态，不是完整远程桌面协议。

桌面设置含视图、背景、隐藏文件和应用下载阈值。桌面外观写入远程配置；应用设置和已知主机记录写入 Electron 当前用户的 `userData/settings.json`，不写入仓库。原 `remoteDesktopDemo.*` VS Code 设置不再作为独立应用的配置来源。

远程配置继续按下列顺序读取，首个存在的配置无效时显示错误，不悄悄跳过并覆盖：

1. `<Desktop>/.remote-desktop.json`
2. `<Desktop>/config.json`
3. `<home>/.config/remote-desktop/config.json`
4. `<home>/.remote-desktop.json`

配置上限为 64 KiB。未知字段保留；原 VS Code 命令快捷方式保留在 JSON 中，但在独立界面跳过，且不执行。固定 Shell/Vim/htop 和真实符号链接仍可使用。保存既有配置使用 OpenSSH 原子重命名扩展；服务器不支持时明确失败并保留原文件，不通过删除旧配置降级覆盖。
