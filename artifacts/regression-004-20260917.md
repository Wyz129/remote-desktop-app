## 本轮改动

1. 远程 Delete 和右键删除使用相同路径：一次确认后永久删除，不调用远程回收站；取消无副作用，删除符号链接不递归到目标。
2. 同名复制自动编号，文件编号放在扩展名前，目录编号放在完整名称后；不覆盖现有目标。剪切移动仍拒绝同名覆盖。
3. 桌面内 xterm.js + 原生 PTY 终端，支持 shell、Vim、htop，多窗口、缩放与最小化。
4. 将上述程序固定到左栏，配置写入服务器桌面，重开后保留；不自动启动程序。
5. 顶栏显示服务器账号、连接状态和服务器时区时间，每 30 秒同步。
6. 桌面和资源管理器右键菜单增加刷新当前目录。
7. 修正隐藏 Webview 时零尺寸覆盖窗口位置的问题。

## 边界

- Vim 的整段 `type_text` 粘贴尝试未通过，观察到触发 Ctrl-V 模式；不能据此宣称终端粘贴正常。本轮验证了单按键输入，中文输入与保存文件未覆盖。
- 真实 SSH 断连后的状态变化和恢复未实测；失联提示及恢复仅由自动化模拟消息覆盖。
- 固定程序本版支持终端、Vim、htop；程序需在服务器预先安装并位于 PATH。
- 固定程序从桌面根目录启动；在选中文件夹上右键打开终端使用其所在目录，要在文件夹内启动请先进入该目录，再右键空白处。
- 关闭整个桌面会结束其 PTY 会话；这不是后台任务保持工具。
- 原生 PTY 复用当前 VS Code Server 模块，未来内部安装布局变化可能需要兼容更新。
- 历史跨窗口拖放问题本轮未复测，旧报告中的未通过项不能因其他功能通过而视为解决。
