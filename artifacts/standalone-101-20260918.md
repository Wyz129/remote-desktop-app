## 本轮行为

- 应用打开的 Vim 在点击红叉时询问“保存并关闭 / 不保存关闭 / 取消”。保存使用 `:wqa`，不保存使用 `:qa!`；等待正常退出后才移除窗口。只读、未命名缓冲区、E325 启动恢复提示和超时都保留终端，避免直接中断进程。
- 断开 SSH、切换连接、原生应用红叉和退出同样经过保护；取消时保留当前连接和编辑器。桌面刷新失败或根目录变化也不再销毁编辑器窗口。
- Shell 中手动启动的编辑器提供关闭提醒，需先在终端保存并正常退出。无法保证意外断网、系统强杀或断电时的保存；已有 swap 不会自动删除，应先处理恢复。
- 左侧任务栏内建 Home、设置，独立于用户固定程序。Home 使用真实登录主目录；缺少 Desktop 时仍能访问 Home，不自动创建目录。
- 设置控制面板整合桌面外观、隐藏文件、下载阈值、SSH 连接管理，以及系统版本、CPU、内存、磁盘、网络、时间、时区和语言信息。远程系统信息为可刷新只读快照；系统级变更仍需在有相应权限的终端完成。
