# Remote Desktop 0.0.6 回归与交付

日期：2026-09-18。项目：`C:\0_myfiles\new_projects\remote-desktop`。

## 本轮实现

- 项目目录、package 名称改为 remote-desktop，显示名称 Remote Desktop，版本 0.0.6。Git 主分支 main，初始回退提交 4d4cef1 保留 0.0.5 源码；私有仓库为 https://github.com/Wyz129/remote-desktop。
- 扩展 ID 改为 local-demo.remote-desktop，主命令为 remoteDesktop.open。保留 remoteDesktop.openDemo 隐藏别名、remoteDesktopDemo.* 设置和服务器桌面配置格式。安装新包前须禁用或卸载旧 ID local-demo.remote-desktop-demo；旧 Webview 窗口会话不迁移。
- 全屏移到 32px 顶栏，使用单个纯图标，右键菜单入口已移除。每次只切换一次 VS Code 禅模式。按用户选择，工作区 zenMode.centerLayout 保持 false，无工作区时使用用户级设置。系统全屏仍遵循 zenMode.fullScreen；再次点击图标或双 Esc 退出。
- 桌面使用容器百分比尺寸和 ResizeObserver，自适应编辑区变化；内部最大化窗口与终端重新计算尺寸，隐藏 Webview 零尺寸不覆盖位置。普通窗口保留用户选择的尺寸，仅约束到可见边界。
- 顶栏设置图标打开桌面内设置窗口：详情/图标视图、青绿/暮紫/石墨背景、隐藏文件显示。默认背景青绿，默认显示隐藏文件以兼容旧版。
- 设置保存等待服务器确认，成功后应用，失败可重试，取消保持旧值；超时提示结果未确认。配置合并保留未知字段，隐藏项不进入旧选区的后续操作；删除偏好字段后刷新恢复默认值。
- 测试脚本移除个人 Code 安装路径依赖。Extension Host 使用隔离夹具工作区，避免修改项目或用户当前窗口的设置。

## 未覆盖与限制

- 用户要求不执行需要电脑操作技能的验证。本轮没有使用该技能，没有在现有 SSH 窗口安装新版，也没有声明新功能已完成真实 SSH UI 验收。
- 本机 Extension Host 测试将 zenMode.fullScreen 设为 false，验证真实禅模式命令及工作区偏好；原生 OS 全屏动画、手动退出与平台差异仍需实机观察。
- 自适应针对当前 Webview 所在编辑区；现有多个 VS Code 编辑器组不会被插件合并，也不会关闭其他编辑器。
- 保留历史限制：F5 可能同时触发宿主调试选择器、真实断连恢复未测、PTY 依赖 VS Code runtime 目录。0.0.5 后续抽测已验证一次跨窗口移动以及 Vim Ctrl+Shift+V 中文多行粘贴/保存，详见 docs/mcp-live-ui-review-20260917-b73f.md；不能泛化为所有拖放/IME 情况均通过。
