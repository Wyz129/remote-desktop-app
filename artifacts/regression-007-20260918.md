日期：2026-09-18。项目：`C:\0_myfiles\new_projects\remote-desktop`。修改前回退提交：`a8ec8a5`（0.0.6）。

## 本轮实现

- 桌面和资源管理器新建项目的默认名改为 `New Folder`、`New File.txt`；同名使用 `New Folder (2)`、`New File (2).txt` 等，确认名称后才创建。
- 桌面设置窗口含 `@ext:local-demo.remote-desktop` 的全部四项 VS Code 扩展设置：自动启动、本地示例根目录、远程主目录、脚本默认编辑器。工作区/用户范围可选；仅保存明确编辑过的字段，回读实际有效值，工作区优先。
- 扩展设置与桌面外观分开保存。设置事务串行处理、读取等待写入完成；多项写入失败时尝试回滚原目标层值并显示错误。外部配置更新同步生效，同时保留独立表单基线，避免保存其他字段时覆盖外部更改。
- 当前面板冻结目录映射；改 remoteRoot/remoteHome 后持续提示关闭重开才生效，现有文件和终端操作仍使用原目录。本地示例重开时同步重映射示例条目。
- Webview 聚焦时 Ctrl+Alt+T 打开内嵌终端，优先使用聚焦虚拟窗口目录；捕获阶段拦截，不向 xterm 发送此组合键。设置弹窗打开时不启动终端，重复按键和输入法组合不触发。
- 新设置 `remoteDesktopDemo.scriptEditor` 可选 `vscode`（默认）或 `vim`。选择 Vim 后，双击常见扩展名脚本会在桌面新开 Vim 窗口。普通文件保留 VS Code 打开，文件夹保留虚拟导航。
- Vim 文件路径经原路径、原生主机、真实链接目标和普通文件校验，通过 `['--', absoluteFilename]` 传给 PTY；不把文件路径拼成 shell 命令，不执行脚本。支持空格、中文、单引号等文件名；缺少 Vim 明确显示错误。

## 测试限制

- 本轮按用户此前指示不使用电脑操作技能，未在用户当前 SSH 窗口安装新版，未做真实 SSH UI 验收。
- Ctrl+Alt+T 是 Webview 内快捷键，未注册为 VS Code 全局快捷键。操作系统/桌面环境可能先截获同一组合键，真实 SSH 窗口仍需人工复测。
- 本轮真实 PTY 测试运行本机 shell；新增 Vim 文件参数和窗口路由由 PTY/后端/UI 测试覆盖，没有在服务器 Vim 中实际编辑并保存。Vim 必须已安装且位于扩展主机 PATH。
- 脚本以扩展名识别，列表见 README；无扩展名 shebang 文件暂不识别。支持范围并不表示已在各种语言运行时执行脚本，本功能只打开编辑器。
- 禅模式测试设置 fullScreen=false，不能视为原生 OS 全屏视觉验收。历史 F5 宿主快捷键冲突、真实断连恢复和 IME 逐字输入等限制仍见 HANDOFF。
- 0.0.5 历史 SSH 抽测已经观察到 Vim 中文多行粘贴和保存、跨窗口移动成功；不将这些历史结果算作 0.0.7 验收。
