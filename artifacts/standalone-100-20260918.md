## 完成的功能

应用启动即全屏显示独立桌面和 SSH 连接窗口；支持密码或本地私钥/口令。首次原生对话框核验主机 SHA-256 指纹，后续严格校验记录。私钥仅读取原生选择器选中的路径，内容在主进程使用，页面没有本地 file URL 读取能力；密码和密钥不写设置或日志。

SSH 登录后从实际 `$HOME` 找 Desktop/desktop/桌面，无目录时仅在确认后创建，失败/断连不回退 Demo。延续多窗口、导航、拖动/缩放、选区、文件操作、设置和 SSH xterm。普通文件在远程 Vim 打开，脚本不会自动执行；旧 VS Code 命令快捷方式保留配置数据但不显示失效入口。

栅格图片在虚拟桌面窗口中初始适配，支持围绕鼠标位置放大/缩小、拖动平移、100%、最小化/最大化。支持 PNG/JPEG/GIF/WebP/BMP/AVIF；单图 25 MiB 上限，不预览 SVG。

所有文件/目录右键可下载到系统 Downloads。默认小于 50 MiB 使用 SSH exec 二进制流，达到阈值使用 SFTP；目录全部递归 SFTP。SFTP 本身是 SSH 子系统。阈值可设 1–1024 MiB；独占暂存、同名编号、进度、取消、失败与断开清理均实现，不覆盖既有目标。

远程配置使用四级兼容查找和 64 KiB 限制，串行回读、保留外部修改及未知字段、临时文件加原子替换。固定程序生成稳定 ID 并去重，使用同一个配置服务。SFTP 流等待远程 CLOSE 确认，修复了 EOF 后立即断开导致未处理错误的生命周期问题；关闭应用也等待下载清理完成。
